# AMAZON_INDIA_SALES_DASHBOARD

An interactive Amazon India Sales Analytics Dashboard built in Microsoft Excel to analyze sales performance, profitability, order trends, product performance, customer order outcomes, payment methods, fulfillment models, and geographic sales distribution.The dashboard combines data analysis, Pivot Tables, Pivot Charts, KPIs, and interactive slicers

The dashboard combines data analysis, Pivot Tables, Pivot Charts, KPIs, and interactive slicers to transform raw Amazon India sales data into actionable business insights.

📊 Project Overview

The objective of this project is to analyze Amazon India sales data and develop an interactive dashboard that enables users to monitor key business metrics and explore sales performance across multiple dimensions.

The dashboard provides a consolidated view of:

Sales performance
Profitability
Order volume
Units sold
Average Order Value (AOV)
Profit margin
Return performance
Cancellation performance
Product performance
Category performance
Payment methods
Fulfillment models
State-wise sales
🎯 Business Objectives

The project focuses on answering important business questions such as:

What is the total sales and profit generated?
How many orders and units were sold?
What is the Average Order Value?
What is the overall profit margin?
Which product categories generate the highest sales?
Which products are the top performers?
What are the monthly sales and profit trends?
Which payment methods contribute the most to sales?
How do different fulfillment models perform?
Which Indian states generate the highest sales?
What is the overall return rate?
What is the cancellation rate?
How do return and cancellation rates vary by category?
What is the distribution of different order statuses?

📈 Dashboard Visualizations

The dashboard contains multiple interactive charts:

1. Monthly Sales & Profit Trend

Analyzes monthly sales and profitability to identify changes in business performance over time.

2. Category-Wise Sales

Compares sales generated by different product categories.

3. Top 10 Products

Identifies the products contributing the highest sales.

4. Order Status Analysis

Provides an overview of order outcomes such as delivered, cancelled, returned, and other statuses.

5. Category-Wise Order Status

Analyzes order outcomes across different product categories.

6. Payment Method-Wise Sales

Compares sales generated through different payment methods.

7. Fulfillment Model-Wise Sales

Analyzes sales performance across fulfillment models.

8. Ship State-Wise Sales

Highlights sales distribution across Indian states.
